# 半休・半休以上かんたん計算（高円寺営業所専用）

高円寺営業所のスタッフが、1日の一部だけ有給を取得するときに、勤革時（きんかくじ）の「補助項目申請」へ何を入力すればよいかを自動計算する、小さなスマートフォン向けWebアプリです。

**このアプリは勤革時そのものではありません。** 勤革時へのログインや自動操作は一切行わず、「補助項目申請にはこう入力してください」という内容を画面に表示するだけのツールです。設定データはお使いの端末の中だけに保存され、外部（インターネット上のどこか）へ送信されることはありません。

---

## このアプリが計算してくれること

1日の一部だけ有給を取るとき、スタッフが毎回頭の中で考えている、

- 有給が何時間になるか
- 「半日有休」か「全日扱い」か
- どの補助項目を選べばよいか
- 補助項目に入力する開始時刻・終了時刻
- 休憩の扱い

を自動で計算し、「勤革時にはこう入力してください」という形で表示します。

---

## 初回設定（最初の1回だけ）

1. アプリを開くと、まだ設定がない場合は自動的に「曜日ごとの勤務設定」画面が開きます。
2. 月〜日それぞれについて、
   - 「勤務日」かどうか（チェックボックス）
   - 通常勤務開始時刻
   - 通常勤務終了時刻
   - 通常休憩（分）
   を入力してください。**所定労働時間は自動で計算されるので、入力する必要はありません。**
3. 曜日ごとの勤務時間がほとんど同じ場合は、
   - 「月曜日の内容を火〜金へコピー」ボタン
   - 「コピー元」「コピー先」を選んでの「選択した曜日へコピー」ボタン
   を使うと入力の手間を減らせます。
4. 入力が終わったら「保存して戻る」を押してください。

一度設定すれば、普段はこの設定画面を開く必要はありません。設定を直したいときは、画面右上の歯車アイコン（⚙️）から開けます。

---

## 普段の使い方

1. 「有給を取る日」をカレンダーから選ぶ
2. 「有給開始」の時刻を入力する
3. 「有給終了」の時刻を入力する
4. 「計算する」を押す

これだけです。結果として、

- 半日有休 / 全日扱い の判定
- 補助項目申請に入力する「補助項目名」「開始時刻」「終了時刻」
- 有給時間

が表示されます。「勤務中に実際に取る休憩」を自分で選ぶ必要はありません。全日扱いの場合の休憩時間は、会社ルールに基づきアプリが自動で判定します。

表示された内容を見ながら、ご自身の会社貸与スマホ等で勤革時の補助項目申請へ入力してください。**このアプリから勤革時へ自動で入力されることはありません。**

---

## 対応しているケース / 対応していないケース

### 対応しているケース

- 有給が通常勤務の**始業側（午前側）**にあるケース（例: 9:00〜14:00だけ休む）
- 有給が通常勤務の**終業側（午後側）**にあるケース（例: 13:00〜18:00だけ休む）
- 半日有休（有給時間が所定労働時間の半分以下）
- 全日扱い（有給時間が所定労働時間の半分を超える。1日まったく休むという意味ではありません）
- 全日扱いのときの休憩の自動判定（会社ルールに基づき、勤務中に取る休憩をアプリが自動で判定）

### 対応していない・対象外のケース

- **丸1日の有給休暇**：もともと計算が単純なため、このアプリを使う必要がありません。「このツールの対象外です」と表示されます。
- **中抜け有給**（勤務→有給→勤務のように、1日の途中だけ有給を挟むケース）：現在未対応です。「未対応」と表示されます。
- 勤務日として設定していない曜日への申請：エラーになります。
- 有給時間が30分単位でない入力：エラーになります（開始・終了の時刻自体は自由に入力できますが、その差が30分単位である必要があります）。
- 有給時間が所定労働時間を超える入力：エラーになります。

---

## 「補助項目：未確定」と表示された場合

全日扱いのとき、有給側で処理する休憩時間が **60分・30分・0分以外**（例: 45分）になった場合、計算そのものは最後まで行いますが、その分数に対応する会社の補助項目名がまだ確認できていないため、「補助項目：未確定」と表示されます。

この場合、

- 開始時刻・終了時刻・有給時間は表示された計算結果のとおりで問題ありません
- 補助項目名だけは、所長または既存の資料でご確認ください

未確定の対応表は `js/companyRules.js` に集約されているので、会社側で新しい補助項目名が確認できた場合は、その1ファイルに1行追加するだけで自動的に反映されるようになっています。

## GitHub Pagesでスマホから使う方法

このリポジトリをGitHub Pagesで公開すると、スマートフォンのブラウザからそのままアクセスして使えます。

1. GitHubのリポジトリ設定（Settings）→「Pages」を開く
2. 「Source」で公開したいブランチ（例: `main`）とルートフォルダ（`/`）を選択して保存する
3. しばらくすると `https://（ユーザー名またはOrganization名）.github.io/kinkakuji-app/` のようなURLが発行されます
4. スマートフォンのブラウザ（iPhoneならSafari、AndroidならChrome）でそのURLを開く
5. 「ホーム画面に追加」を行うと、アプリのようにアイコンから起動できるようになります（PWA対応）
   - iPhone（Safari）: 共有ボタン →「ホーム画面に追加」
   - Android（Chrome）: メニュー →「ホーム画面に追加」／「アプリをインストール」
6. 一度開いた後は、電波が悪い場所でも基本画面が表示されます（完全なオフライン対応ではなく、一度読み込んだ内容のキャッシュによるものです）。

## 設定データについて

- 曜日ごとの勤務設定は、お使いの端末のブラウザの中（localStorage）だけに保存されます。
- 氏名・社員番号などの個人情報は入力しません。
- 勤革時のID・パスワードは一切扱いません。
- インターネット上のどこにもデータを送信しません。
- ブラウザのデータを消去したり、別の端末で開いたりすると、設定は引き継がれません。その場合は初回設定をやり直してください。

## 開発者向け情報

### ファイル構成

```
index.html            画面（通常利用・設定の両方を1ファイルに含む）
css/style.css         スタイル
js/companyRules.js    会社独自ルール（補助項目名・対応表）だけを集約
js/calculator.js      計算ロジック（純粋関数、DOM非依存）
js/storage.js         localStorageへの保存・読込
js/app.js             画面表示・入力受付（UI層）
manifest.json         PWA用マニフェスト
service-worker.js     オフラインキャッシュ用のService Worker
icons/                アプリアイコン
tests/calculator.test.js  計算ロジックの自動テスト
```

会社独自ルール（休憩60分/30分/0分と補助項目名の対応など）は `js/companyRules.js` にすべて集約しています。新しいルールが確認された場合は、このファイルに追記するだけで対応できます。UI（`js/app.js`）や計算ロジック（`js/calculator.js`）にルールをif文で埋め込まないでください。

### テストの実行方法

Node.js（18以上を推奨、開発時は22で確認）があれば、追加のインストールなしでテストを実行できます。

```
npm test
```

内部的には Node.js 標準の `node --test` を使っています。

### ローカルでの動作確認方法

このアプリはビルド不要の素のHTML/CSS/JavaScriptです。ローカルで確認する場合は、`index.html` をブラウザで直接開くのではなく、簡易的なHTTPサーバー経由で開いてください（`file://`ではES ModulesとService Workerが正しく動作しない場合があります）。

```
npx serve .
```

または任意の静的ファイルサーバーで、リポジトリのルートを配信してください。
